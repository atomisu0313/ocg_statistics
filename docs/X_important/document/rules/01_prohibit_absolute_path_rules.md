# ルール: ドキュメント内における絶対パス（フルパス）記述の厳格禁止

本リポジトリ（`ocg_statistics`）配下のすべてのドキュメント（`docs/` 配下および各ディレクトリの `README.md` 等）において、**ローカルマシンの絶対パス（フルパス）や個人ユーザー名を含むパスの記述を厳格に禁止**し、必ず**相対パス**で記述することを義務付けます。

---

## 1. 背景と目的

ドキュメント内に `/Users/<ユーザー名>/...` や `file:///Users/<ユーザー名>/...` などの絶対パスを記述すると、以下の重大な問題が発生します：

1. **個人情報・環境情報の漏洩**:
   - 開発者のローカルユーザー名やマシン固有のディレクトリ構造が Git 履歴や公開リポジトリに永続化される。
2. **リンク機能の破綻（ポータビリティの喪失）**:
   - 別の開発者のマシン、GitHub Web UI、または CI 環境でドキュメントを閲覧した際、絶対パスのリンクは 404 エラーとなり機能しない。
3. **メンテナンス性の低下**:
   - ディレクトリの移動やプロジェクト名の変更時に、大量の絶対パスを書き直す必要が生じる。

---

## 2. 遵守ルール一覧

1. **ローカル絶対パス（`/Users/...`, `C:\...`）の記述禁止**:
   - ドキュメント内のいかなる場所（リンク、テキスト、見出し）にも、ローカルマシン固有の絶対パスを記述してはならない。
2. **`file://` スキームのドキュメント内記述禁止**:
   - `file:///Users/...` のようなローカル URL スキームは、Git リポジトリ内の Markdown ドキュメントに記述してはならない。
3. **ファイルリンクは必ず相対パスで記述すること**:
   - Markdown リンクは、そのファイル自身が存在するディレクトリを起点とした相対パス（`./` または `../`）で記述する。
4. **コードやコマンド例でのパス表記は「リポジトリルート相対」とすること**:
   - コマンド例（`cd code/...` 等）やファイル配置の説明を行う際は、リポジトリルートを起点とした相対パス（例: `code/cardApiCall/infoInsert/...`）を用いる。

---

## 3. 記述例

### ⭕ 正しい記述例

#### 1. 同一ディレクトリ内のリンク
```markdown
詳細は [01_new_table_creation_rules.md](./01_new_table_creation_rules.md) を参照。
```

#### 2. 親ディレクトリや別ディレクトリへの相対リンク
```markdown
詳細は [docs/04_new_tables/](../04_new_tables/01_new_table_implementation_guide.md) を参照。
```

#### 3. コマンド・コード例でのパス表記
```bash
# リポジトリルートを起点としたパスで記述
cd code/cardApiCall/infoInsert
go test ./...
```

---

### ❌ 違反例（アンチパターン）

#### 1. フルパス（ユーザー名入り）のリンク
```markdown
<!-- ❌ 違反: ユーザー名が含まれ、他者の環境や GitHub でリンクが壊れる -->
[手順書](file:///Users/username/myprj/ocg_statistics/docs/04_new_tables/README.md)
[手順書](/Users/username/myprj/ocg_statistics/docs/04_new_tables/README.md)
```

#### 2. コマンド例に絶対パスをハードコードする
```bash
# ❌ 違反: 実行環境が限定されてしまう
cd /Users/username/myprj/ocg_statistics/code/cardApiCall/infoInsert
```

---

## 4. チェックリスト

ドキュメントを作成・更新した際は、PR 作成前に以下を確認してください：

- [ ] ドキュメント内に `/Users/` や `C:\Users\` などの絶対パスが含まれていないか？
- [ ] すべてのファイルリンクが相対パス（`./` や `../`）で記述されているか？
- [ ] `file://` スキームのリンクが存在しないか？
- [ ] 記載した相対リンクをクリックして、正常に対象ファイルへ遷移できるか？
